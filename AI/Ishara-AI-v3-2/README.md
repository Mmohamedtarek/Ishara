# Ishara Glove: جزء الـ AI (v3.2، كلمات ASL)

**v3.2:** الكلمات من ملف Sign Vocabulary v2 (ASL): `good` و`bad` اتبدلوا بـ `water` و`bye`، وحركات `hello` (تحية من الجبهة) و`no` (السبابة والوسطى بيقفلوا على الإبهام) بقت بشكل ASL. `run_pipeline.sh` بقى بيدرّب الأول قبل الـ mining، وبيمسح الموديلات القديمة في الأول.

## الملفات

| الملف | بيعمل إيه |
|---|---|
| `common.py` | الحاجات المشتركة: شكل الداتا، المعايرة، وتجهيز كل take |
| `glove.py` | الكلام مع الجلوف: البورت، التأكد إن الداتا شغالة، وطلب المعايرة (`#CAL`) |
| `simulate_data.py` | داتا وهمية للـ 22 فئة (Sign Vocabulary v2، ASL) لحد ما الجلوف يجهز (ومعاها ملف معايرة لكل شخص وهمي) |
| `record.py` | تسجيل الداتا الحقيقية من الجلوف |
| `train_rf.py` | الموديل الأول: Random Forest (خط الأساس، سريع) |
| `train_cnn.py` | الموديل النهائي: 1D-CNN، وبيطلع ملفات TFLite للموبايل والـ ESP32-S3 |
| `live.py` | التوقع الحي: الكلمة تظهر على الشاشة وتتقال بصوت |
| `eval_live.py` | التقييم الكامل: WER على الجمل، والكلمات اللي بتطلع لوحدها في ساعات من الحركة العادية، والتأخير، ودقة كل إشارة، واختبارات ضغط. `--tune` بيضبط الـ Decider، و`--sessions` بيقيس جلسات لبس 3 ساعات |
| `mine_negatives.py` | بيلاقي الحركات العادية اللي الموديل فاكرها إشارة ويضيفها لفئة other (Hard Negative Mining) |
| `build_kit.py` | بيجهز Ishara-Mobile-Kit لفريق الموبايل من الموديل الحالي |
| `run_pipeline.sh` | الخطوات كلها ورا بعض على الداتا الوهمية |
| `decider.json` | إعدادات القرار (الثقة، الـ hold، ...) |
| `requirements.txt` | المكتبات المطلوبة |

الموديلات: `ishara_cnn.tflite` (للموبايل)، `ishara_cnn_int8.tflite` (للـ ESP32-S3)، `ishara_cnn.keras`، `ishara_rf.joblib`.

## التسطيب على Ubuntu (بيئة واحدة بـ Python 3.12 تكفي لكل حاجة)

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
sudo apt install espeak-ng          # عشان الصوت في live.py
sudo usermod -aG dialout $USER      # عشان تقرا من الجلوف (اعمل logout مرة بعدها)
```

على Windows نفس الكلام، بس التفعيل `.venv\Scripts\activate`، ومحتاج Python 3.12 عشان TensorFlow.
الجلوف بيظهر كـ `/dev/ttyACM0` أو `/dev/ttyUSB0` على Ubuntu، و `COM3`/`COM5` على Windows، والسكريبتات بتلاقيه لوحدها.

## 1. التجربة على الداتا الوهمية

```
python simulate_data.py
python train_rf.py
python train_cnn.py
python eval_live.py              # الـ CNN على جمل كاملة
python live.py --sim             # تشوف وتسمع الجمل التجريبية
```

## 2. لما الجلوف يجهز

1. امسح فولدر `data` (ده الوهمي).
2. **لكل شخص، المعايرة مرة واحدة:**
   - عاير الجلوف نفسه: من التطبيق، أو من الـ Serial Monitor بحرف `c`، وامشي في الخطوات التلاتة
     (افتح إيدك ← اقفل إيدك ← لفّ رسغك).
   - بعدين: `python record.py calib ahmed` ← بياخد المعايرة من الجلوف ويحفظها في `data/calib/ahmed.json`.
3. سجّل كل إشارة 20 مرة: `python record.py water ahmed`.
   كل Enter بيعدّ 3، 2، 1، وبعدين بيسجّل ثانيتين.
4. شغّل `train_rf.py` و `train_cnn.py --full`، وقارن الدقة.
5. شغّل `eval_live.py` عشان تشوف الدقة على جمل كاملة زي الديمو.

الرقم اللي هتقوله في المناقشة هو **"الدقة على أشخاص جداد"**، مش الدقة على إيدك إنت.

## 3. التوقع الحي مع الجلوف

```
python live.py                   # بياخد المعايرة من الجلوف
python live.py --person ahmed    # لو الجلوف مش متعاير، بيستخدم معايرة ahmed المحفوظة
```

لو مفيش معايرة خالص، `live.py` بيعمل معايرة سريعة (افتح إيدك، اقفل إيدك).
أوامر إضافية: `--model rf` عشان تستخدم Random Forest، و `--mute` من غير صوت، و `--port COM5`.

## ملف المعايرة

الجلوف لما يوصله حرف `j` بيرد بسطر:
```
#CAL {"v":2,"open":[...5],"fist":[...5],"gyro_bias_raw":[gx,gy,gz],"roll_neutral":..,"roll_min":..,"roll_max":..}
```
- `open` و `fist`: قراءة الـ 5 صوابع (0–4095) وهي مفتوحة ومقفولة.
- `gyro_bias_raw`: الـ gyro bias **بنفس وحدة الـ stream الخام** (65.5 = 1°/s). لو الفيرموير بيبعتها بـ °/s
  باسم `gyro_bias` أو `gyro_bias_dps`، `common.parse_glove_cal` بيحوّلها لوحده.
- الـ bias بيتطرح من الجيروسكوب قبل الموديل، فاختلاف الحساس من جلوف لجلوف مبيأثرش.

لسه ينفع تسجّل `calib_open` و `calib_fist` بالطريقة القديمة (`python record.py calib_open ahmed`) لو الجلوف مش بيبعت `#CAL`.
وقتها الـ gyro bias بيتحسب من تسجيل الإيد المفتوحة، لأنها بتبقى ثابتة.

## الجديد في النسخة دي (v2)

- المعايرة جاية من الجلوف نفسه (`#CAL`)، فالمستخدم بيعاير مرة واحدة بس، بنفس خطوات التطبيق.
- الـ gyro bias بيتطرح قبل الموديل.
- عدّ تنازلي 3-2-1 قبل كل take في `record.py`.
- `record.py` و `live.py` بيستنوا البورد تقوم بعد فتح البورت، وبيشغّلوا الـ raw stream لو كان مقفول.
- الأسامي بقت `ishara_*` بدل `sayn_*`.
- ملف الـ Random Forest بقى مضغوط: 22 ميجا بدل 193.

## الجديد في v3

- **فئة `other`:** حركات عادية مش إشارات (كتابة، موبايل، كوباية، إشارة بالإيد، شنطة...). من غيرها الموديل كان مضطر يختار إشارة لأي حركة.
- **Hard Negative Mining** (`mine_negatives.py`): جولتين، كل جولة بتلاقي الحركات اللي الموديل غلط فيها وبتدرّبه عليها.
- **Augmentation جديد** في `train_cnn.py`: لف الـ MPU لحد 25°، وسرعة الإشارة من 0.65× لـ 1.5×، وحساس صباع واقف، وتغيّر الحساسات بعد المعايرة.
- **Ensemble من 3 موديلات CNN** (`train_cnn.py --member 2` و `--member 3`): التوقع = متوسط التلاتة.
- **Decider جديد** في `live.py`، والترجمة شغالة على طول من غير زرار:
  - **idle:** أول كلمة لازم تبقى واضحة جدًا، أو تظهر **مبدئية** وتتأكد لو جت بعدها كلمة تانية أو فضلت واضحة، وتتشال لو مجاش حاجة.
  - **active:** جوه المحادثة، الانتقال من كلمة لكلمة سريع، ويرجع idle بعد 4 ثواني من غير كلام.
  - الإعدادات في `decider.json`.
- **تسجيل الحركة العادية من الجلوف الحقيقي:** `python record.py wear ahmed 60` وبعدين `python mine_negatives.py --from-recording ahmed`.

| | v2 | v3.1 (كلمات v1) | **v3.2 (كلمات ASL)** |
|---|---|---|---|
| كلمات بتطلع لوحدها في الدقيقة (60 ساعة لبس) | 7.75 | 0.0003 (أقصى رقم بثقة 95%: 0.0013) | **0.0014** (أقصى رقم بثقة 95%: 0.0029) |
| كلمات بتطلع لوحدها في 30 ساعة حركة عادية | — | 0 | 2 (0.0011 في الدقيقة) |
| WER على الجمل | 14.1% | 9.4–10.6% | **9.1–10.3%** |
| كلمة مبدئية ظهرت واتشالت | — | حوالي مرة في الساعة | حوالي مرتين في الساعة |
| دقة الإشارة لوحدها | 89.6% | 94.8% | 95.6% |
| الجلوف متلبس مايل 30° | 76.5% | 96.1% | 96.0% |
| حساس بايظ | 72.6% | 83.5% | 85.9% |

أضعف حاجة لسه: **one / me / you** (نفس شكل الإيد، والفرق في الاتجاه بس)، و**water / two** شوية، و**drink / hungry** لما بييجوا لوحدهم، لأنهم شبه حركات عادية (كوباية، إيد نازلة على البطن). مع الداتا الحقيقية ركّزوا على تسجيلهم بزوايا واضحة، وسجّلوا حركات عادية كتير شبههم كـ other.

### الخطوات مع الجلوف الحقيقي

```
python record.py calib ahmed            # لكل شخص
python record.py <sign> ahmed           # كل إشارة 20 مرة، و other حوالي 60 مرة
python record.py wear ahmed 60          # ساعة لبس عادي من غير إشارات
python mine_negatives.py --from-recording ahmed
python train_rf.py && python train_cnn.py && python train_cnn.py --member 2 && python train_cnn.py --member 3
python eval_live.py --tune              # ⚠️ بيضبط على الداتا الوهمية لحد ما يبقى فيه أشخاص حقيقيين كفاية
python build_kit.py ../Ishara-Mobile-Kit   # وابعت model/ لفريق الموبايل
```
